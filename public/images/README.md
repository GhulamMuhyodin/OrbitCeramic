# Orbit Ceramic images

Put photos in `public/images` using this naming pattern:

```
/images/{section}/{name}-01.jpg
/images/products/{slug}/{slug}-01.jpg
/images/products/{slug}/{slug}-02.jpg
/images/products/{slug}/{slug}-03.jpg
```

## Sections
| Path | Example |
|------|---------|
| `hero/hero-01.jpg` | Homepage hero |
| `about/about-01.jpg` | About maker |
| `collections/{id}-01.jpg` | `earth-01.jpg`, `stoneware-01.jpg` |
| `video/video-01.jpg` | Video poster |
| `products/{slug}/{slug}-NN.jpg` | Multiple angles per ceramic |

Use zero-padded numbers: `01`, `02`, `03`.
