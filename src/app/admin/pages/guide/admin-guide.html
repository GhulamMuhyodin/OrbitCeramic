How to publish content

Content is saved to MySQL via orbit-api. Keep the API running (START-API.bat) while using admin.

  1. Start API: orbit-api\START-API.bat → http://localhost:8080/api/v1/health
  2. Run Angular with proxy: ng serve (proxies /api → :8080).
  3. Site & Contact → set brand / WhatsApp → Save to database.
  4. Batches → Add batch → products, upload images, journey, highlights → Save on the batch screen.
  5. Optional: About and Reviews → Save on each page.
  6. Open the public site — it loads GET /api/v1/bootstrap (nav/footer still from JSON).

API key is in src/app/config/api.config.ts (must match orbit-api/config/config.php).
